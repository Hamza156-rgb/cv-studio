# Resume layout research notes

- UXfolio, “UX Resume Layout”: https://blog.uxfol.io/ux-resume-layout/
  - Recruiters scan vertically for role titles, companies, dates, outcomes, and portfolio links.
  - Strong hierarchy and prominent portfolio links reduce friction.
  - Consistent order and spacing improve scanability.
- Resume.io, “ATS Resume Templates & Format Guide”: https://resume.io/resume-templates/ats
  - Use conventional section labels and reverse-chronological work experience.
  - Keep dates consistent and use a single-column, readable structure for ATS safety.
  - Decorative elements should not obscure text or parsing.

Applied direction: clear role/company/date/work hierarchy, optional project links only when populated, reverse-chronological sorting, and a compact ATS mode that reduces decorative styling while retaining content.
